# Phase 1：首批手動記帳交付驗證

日期：2026-09-23（America/Los_Angeles）。使用者要求進入 Phase 1，先實作銀行／現金／信用卡、收支、轉帳、圖表及 CSV。此紀錄只涵蓋實際交付功能，不代表 04 的整個 Phase 1 已完成。

## 已交付範圍

- 銀行、現金、信用卡建立／改名／封存，USD/TWD，期初餘額，是否納入淨資產；信用卡溢繳保留負欠款。
- 收入、支出、轉帳、手續費、分類分攤、兩層分類新增、商家／備註／標籤、日期與帳戶／分類／關鍵字查詢及分頁。
- 同幣部分退款，依原交易分類扣減；超退拒絕，原支出有有效退款時拒絕更正／作廢。更正用沖回＋替代，作廢只沖回；expected_revision 與永久提交識別避免重複寫帳。
- 人工入帳匯率、跨 USD/TWD 轉帳與獨立估值匯率。缺估值匯率顯示 partial，舊匯率提示日期；歷史曲線明示為重建。
- 不可變報表快照保存同條件指標／明細／月度／分類／淨資產／來源版本，Web ECharts 與 CSV 使用相同內容。收入 ≤ 0 時儲蓄率不適用；期初與轉帳本金排除收支。
- CSV ZIP 包含 transactions/categories/monthly/summary/accounts.csv、metadata.json；UTF-8 BOM、正確引號換行與公式文字防護，授權下載不回寫帳本。
- 備份涵蓋全部新增財務表，隔離還原核對平衡、筆數、資料指紋、帳戶餘額及固定報表；舊 Phase 0 備份仍可隔離還原。

## 限制與待辦

- 本機備份目前仍在 `data/backups/`；使用者尚未指定外部磁碟／NAS。真實睡眠與 LaunchAgent 證據見 [phase-0-mac.md](phase-0-mac.md)。
- 自動匯率、其他資產／貸款、手動估值、每日淨資產封存、對帳、週期交易、收據附件、完整 CSV/JSON 搬出、分類編輯／封存、正規化商家標籤及跨幣退款仍待後續 Phase 1 任務。
- 真實 Numbers CSV 開檔、iPhone Safari、10 萬筆報表 P95、私人遠端與實際重新登入仍未驗收，不能以桌面模擬器或小型 fixture 取代。
- Vite 目前提示主 bundle 約 755 kB（gzip 約253 kB），含圖表；後續可按頁面分包。未因此調高警告門檻。
- 每份快照目前保留完整明細並同步生成；大帳本的非同步匯出與快照保留策略仍需在效能驗收階段完成。
